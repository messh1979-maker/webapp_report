# Security notes

- Production requires a long random `SECRET_KEY`; the app refuses to boot in `APP_ENV=production` without it.
- Set `COOKIE_SECURE=1` only behind HTTPS. Keep `HttpOnly` and `SameSite=Lax` enabled.
- Login throttling is persistent in `login_throttles`: five failed attempts in 15 minutes lock the username/IP pair for 15 minutes.
- Passwords use Werkzeug scrypt (`scrypt:32768:8:1`).
- Every state-changing route is POST and protected by Flask-WTF CSRF.
- SQL is generated by SQLAlchemy. Sort fields use server-side allowlists.
- Jinja auto-escaping is kept enabled. Dynamic subscription markup is a static template and all server-returned values are assigned through DOM `.value`/`textContent`, never interpolated into HTML.
- Module authorization is enforced on routes and queries, not only by hiding navigation. Telecom additionally uses the global `TELECOM_USER_VISIBLE` rollout gate.
- A city-scoped user receives only its own city rows; the city-comparison API exposes only an aggregate average of other cities, not their records or names.
- Uploaded files are capped at 10 MiB and parsed only as JSON/CSV/XLSX for their relevant route.
- Keep user backup JSON files private: they contain password hashes (never plaintext passwords).
- Put the app behind an HTTPS reverse proxy, restrict database network access, rotate secrets, and back up PostgreSQL regularly.
- Set `TRUST_PROXY=1` only when the app is behind exactly one controlled reverse proxy; leave it `0` when clients reach Gunicorn directly.
- Before public deployment, run a dependency/SAST scan in your CI environment and arrange an independent penetration test.
